# Infinity Tools

An end-game Luanti mod featuring powerful infinity tools with a striking purple and black design. These are the ultimate tools for late-game mining and combat.

## Features

- **Infinity Pickaxe**: Supreme mining speed for stone and ore
- **Infinity Axe**: Instant wood and tree harvesting
- **Infinity Shovel**: Lightning-fast earth digging
- **Infinity Sword**: Devastating end-game combat weapon

All tools feature:
- ⚡ **Extreme speed** (0.005-0.05 second dig times - fastest in game)
- 🛡️ **Unbreakable** (infinite durability)
- 💎 **Maximum dig levels** for all materials
- 💪 **High damage output** (10-20 damage)
- 🎨 **Purple and black aesthetic** - true end-game look

## Crafting Recipes

Requires diamonds and mese blocks - true end-game materials!

### Infinity Pickaxe
```
D D D
  M
  M
```
(D = Diamond, M = Mese Block)

### Infinity Axe
```
D D
D M
  M
```

### Infinity Shovel
```
D
M
M
```

### Infinity Sword
```
D
D
M
```

## Installation

1. Clone this repository into your Luanti `mods` folder
2. Enable the mod in your world settings
3. Restart your world
4. Gather diamonds and mese blocks, then craft your infinity tools!

## Dependencies

- default (Luanti default game)
